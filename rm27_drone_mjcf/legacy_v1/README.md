# Previous RM27 aircraft assets

These visual and dynamic entries were preserved byte-for-byte when Ver2 became
the package's current model on 2026-10-13. `visual/model.xml` is the original
2627drone_ver1 appearance; `dynamic/model.xml` is the provisional 180 g proxy.
`provenance.json` records their prior sources. They do not describe the current
150 g aircraft. Keep `visual/assets/` with its entry when relocating this archive.
