# 过洞步兵 MJCF

直接加载 `model.xml`。所有网格和纹理均使用相对路径；解压后请保留 `assets` 文件夹。

```powershell
python view_model.py
```

## 键盘控制

运行 `view_model.py` 后先点击一次 MuJoCo 窗口，使其获得键盘焦点：

| 按键 | 动作 |
| --- | --- |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 左移 / 右移 |
| `←` / `→` | 云台向左 / 向右转头 |
| `↑` / `↓` | 云台向上 / 向下俯仰 |
| `B` | 在收回和伸出之间切换头部（行程 80 mm） |
| 松开 `W/A/S/D` | 停止底盘 |

底盘采用四轮逆运动学解算和轮速闭环。`W/A/S/D` 与方向键均支持按住连续控制；松开移动键后，下一帧立即把底盘目标速度清零。也支持同时按住两个移动键进行等速斜向移动。

控制器采用云台坐标系：`W` 始终朝云台当前朝向移动，底盘根据云台相对 yaw 自动旋转并重新对正。运行时通过 MuJoCo `MjSpec` 加载 `/home/z/code/wbr/rmuc2026_battlefield_mjcf/model.xml`，移除机器人自身的无限地面，并将机器人放置在场地中央平坦路面 `(0, 3, 0.3)`。

查看器使用 GLFW/OpenGL 硬件 GPU 渲染，并在终端及窗口左上角显示实际 GPU 名称。如果检测到 `llvmpipe`、`softpipe` 等软件光栅器，程序会停止并提示安装或启用显卡驱动。仅在无 GPU 的诊断环境中，可临时设置 `PANCAKE_ALLOW_SOFTWARE_RENDERING=1` 放行软件渲染；MuJoCo 物理求解仍运行在 CPU 上。

已在 MuJoCo 3.12.0 编译、渲染和仿真验证。查看器中 geom group 2 为外观，group 3 为碰撞模型。

## 机构

- 7,488 个原始实体合并为 133 个机器人刚体。
- 4 个轮毂转轴、112 个全向轮辊子转轴，均为连续转动关节。
- 四个轮组各有一套平行四连杆；云台俯仰还有一套平行四连杆。
- 云台偏航、俯仰均可运动，并增加 80 mm 头部伸缩滑动自由度用于交互控制。
- 合计 132 个铰链关节、1 个滑动关节，10 个为闭环从动关节；底盘另有浮动基座。
- 提供 4 个轮毂、4 个折叠、2 个云台和 1 个头部伸缩的通用力/力矩输入。辊子保持被动转动。

## 当前配置的保守运行范围

| 关节 | 范围 |
| --- | --- |
| `fold_6` | 0.0° 至 25.8° |
| `fold_7` | 0.0° 至 24.9° |
| `fold_8` | 0.0° 至 21.8° |
| `fold_9` | 0.0° 至 26.1° |
| `gimbal_pitch` | -11.5° 至 0.0° |
| `gimbal_yaw` | -180.0° 至 180.0° |
| `gimbal_extension` | 0 mm 至 80 mm |

角度相对于 CAD 原始姿态，正方向见 `joint_axes.csv`。这些范围来自碰撞扫描，不是源装配的硬件限位。当前源姿态下俯仰正向会触及护壳，因此保留负向的可动区间。其他机构内部轴承/螺纹及弹链等按所属刚体简化，不包含柔性弹链或执行器内部传动模型。

## 验证

- 初始姿态无自碰撞穿插。
- 122 个独立铰链各扫描 13 个姿态；最大碰撞近似穿入 0.222 mm，在 0.25 mm 检查容差内。
- 2 秒被动仿真无 MuJoCo 数值警告，四连杆动态闭合误差不超过 0.483 mm。
- 四个轮子已通过力矩驱动测试；模型已换目录独立加载。
- 原始 SolidWorks 文件 SHA-256 未改变。

## 明确的近似

源文件为多实体 `SLDPRT`，原装配配合和工程材料未保留。转轴来自原生圆柱面，四连杆由孔轴几何重建。密度、摩擦、关节阻尼、折叠弹簧和力矩范围为可配置的仿真默认值；当前估算质量 23.904 kg，并非实测质量。参数见 `physics_parameters.json`，模型实际数值在 XML 中；修改 JSON 后需重新生成才会作用于 XML。

保留原始 4 张纹理图片。原生 UV 缓存未能稳定读取，部分 UV 根据原纹理尺度与方向重建，纹理相位及接缝可能与 SolidWorks 不同。螺纹、紧固件和轴承内部细节省略；曲面装饰不计入质量。

源护壳与辊子本身存在约 2.55 mm 干涉。碰撞护壳已修出 3 mm 轮子旋转包络间隙，底盘碰撞单元留出 1.5 mm 间隙；视觉外观仍保留源形状。碰撞与视觉网格彼此独立，细小孔隙不全部参与接触。

`conversion_report.json` 包含每个刚体、关节、几何体与源实体的映射、所有近似和检查结果；`previews` 内为源图、渲染图和碰撞图。
