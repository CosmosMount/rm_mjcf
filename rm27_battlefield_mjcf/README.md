# RM27 battlefield

Entry point: `model.xml`.

This is the RM27 field bundle copied from the local updated battlefield
repository. It includes the current hangars, launch areas, tunnels and ground
geometry. Only the 617 mesh files referenced by `model.xml` are included.

The existing `rmuc2026_battlefield_mjcf` bundle is a separate, unchanged
bundle. This directory is the RM27-specific addition.
